# Moaiy v1.0.0 Release Notes (GitHub Release Page Copy)

> **Release Title**: `Moaiy v1.0.0 — Streaming Crypto Pipeline, Keychain & Touch ID Integration, and Companion CLI`  
> **Tag**: `v1.0.0`  
> **Marketing Version**: `1.0.0` (Build `10`)

---

## English

Moaiy **v1.0.0** marks the first General Availability milestone of Moaiy for macOS (14.0+). This release introduces a bounded-memory streaming encryption/decryption pipeline, macOS Data Protection Keychain & Touch ID integration, a standalone `moaiy-cli` companion tool, and hardened App Sandbox file-staging semantics—built on top of the embedded GnuPG 2.5.21 runtime (`gpg.bundle`) with Kyber-768 hybrid post-quantum OpenPGP support.

### Highlights

- **Bounded-Memory Streaming Crypto Pipeline (`StreamingCryptoPipeline`)**: Processes arbitrarily large files in 256KB chunks with independent `stdinQueue`/`stdoutQueue` 8MB backpressure throttling, per-chunk `autoreleasepool` drainage (<32MB Peak RSS delta on 64MB streams), and isolated `0600` passphrase token files.
- **Overwrite-Safe App Sandbox Staging (`commitStagedFile`)**: Calculates net required disk space (`max(0, stagedSize - existingSize)`) via POSIX `statfs`, performs `open(O_WRONLY)` permission preflight, creates a zero-scrubbed rollback backup (`original.bak`), and updates existing destinations in-place (`ftruncate` + stream write + `fsync`) so user-granted `NSSavePanel` sandbox permissions and target file inodes are preserved without data loss.
- **System Keychain & Touch ID Integration (`KeychainService`)**: Stores and retrieves private key passphrases using macOS Data Protection Keychain and `LocalAuthentication` (`.userPresence` for Touch ID, Apple Watch, and device passcode), paired with single-pass primary/subkey fingerprint resolution (`GPGService.resolvePrimaryFingerprint`) and typed `GPGError.ambiguousKeyReference` handling.
- **Memory & Scratch Lifecycle Hygiene (`SecureMemory` & `TransientFileRegistry`)**: Best-effort `memset_s` byte-buffer zeroization on deallocation, automatic zero-scrubbing and purge of active scratch directories on app exit (`NSApplication.willTerminateNotification`), and 24-hour stale scratch directory cleanup on startup.
- **Companion CLI (`moaiy-cli`)**: Standalone command-line utility (`MoaiyCLI` target) supporting `status` (including Kyber-768 capability detection), `list-keys`, `encrypt`, and `decrypt`.

### Detailed Updates

#### Added

- Added `StreamingCryptoPipeline` supporting 256KB chunked streaming I/O, independent `stdinQueue`/`stdoutQueue` backpressure throttling (8MB max in-flight buffer), per-chunk `autoreleasepool` drainage (<32MB Peak RSS delta on 64MB streams), non-blocking `readabilityHandler` IPC, and isolated `0600` passphrase token files.
- Added `CryptoProgress` and `StreamingProgressReporter` with 10Hz UI throttling for responsive progress callbacks.
- Added `SecureMemory` (`SecureBytes`, `SecureString`) providing best-effort internal buffer clearing via Darwin `memset_s` upon deallocation.
- Added `TransientFileRegistry` wired into `SecureTempStorage` and `NSApplication.willTerminateNotification` to zero-scrub and purge active scratch directories upon application exit, plus 24-hour stale directory cleanup on launch.
- Added `KeychainService` integrating macOS Data Protection Keychain with `LocalAuthentication` (`.userPresence`), supporting Touch ID, Apple Watch, and device passcode fallback with thread-safe background lookup and compile-time `#if DEBUG` legacy Keychain fallback isolation.
- Added single-pass `GPGService.resolvePrimaryFingerprint` (`--list-secret-keys --with-colons --fixed-list-mode`) and typed `GPGError.ambiguousKeyReference` to resolve 8-char short IDs, 16-char long IDs, primary fingerprints, and subkey fingerprints in a single subprocess call.
- Added standalone `moaiy-cli` companion command-line tool (`MoaiyCLI` target) with `SIGPIPE` protection and subcommands for `status` (including structured Kyber-768 algorithm detection), `list-keys`, `encrypt`, and `decrypt`.
- Integrated `encryptFileStreaming` and `decryptFileStreaming` into `GPGService` and `KeyActionMenu` with full `decryptFile` parity (`--status-fd 2`, `DECRYPTION_OKAY` verification, recipient key matching, and Keychain passphrase lookup).

#### Changed

- Bumped app marketing version to `1.0.0` and `CURRENT_PROJECT_VERSION` to `10`.
- Hardened `SecureTempStorage.commitStagedFile` with POSIX `statfs` net disk-space calculation (`max(0, stagedSize - existingSize)`), `open(O_WRONLY)` permission preflight, container-backed rollback backup (`original.bak`) with zero-scrubbing, and in-place `ftruncate` + stream write + `fsync` to preserve `NSSavePanel` sandbox security scope and target inode without data loss.
- Initialized `TransientFileRegistry` lifecycle hooks in `MoaiyApp` startup sequence.

#### Security

- Enforced strict `0600` permissions and zero-overwrite scrubbing before `unlink` on temporary passphrase token files and operation scratch directories.
- Restricted legacy macOS Keychain fallback in `KeychainService` strictly to `#if DEBUG` builds (`allowLegacyKeychainFallback`), ensuring Release builds fail closed on missing Data Protection Keychain entitlements.

### Compatibility & Known Notes

- **Post-Quantum Interoperability**: Kyber-768 hybrid OpenPGP keys require GnuPG 2.5.21+ or compatible OpenPGP implementations; use RSA-4096 or ECC when exchanging keys with older OpenPGP tools.
- **Sandbox In-Place Overwrite (`commitStagedFile`)**: To preserve `NSSavePanel` security-scoped file access inside the macOS App Sandbox, overwriting an existing file updates its inode in-place (`ftruncate` + stream write + `fsync`) backed by a zero-scrubbed rollback copy (`original.bak`). If the process suffers an uncatchable crash (`SIGKILL` or power loss) mid-write, the destination file may be left truncated and the rollback backup is retained in `SecureTempStorage` for up to 24 hours.

## 中文（简体）

Moaiy **v1.0.0** 是面向 macOS（14.0+）的首个正式稳定版（GA）。本次发布带来恒定低内存开销的大文件流式加解密管道、macOS Data Protection 钥匙串与 Touch ID 生物识别集成、独立的 `moaiy-cli` 命令行伴侣工具，以及针对 macOS App Sandbox 深度加固的安全原地覆盖机制，并继续内置支持 Kyber-768 混合抗量子 OpenPGP 的 GnuPG 2.5.21 运行时（`gpg.bundle`）。

### 核心亮点

- **恒定低内存流式加解密管道（`StreamingCryptoPipeline`）**：以 256KB 分块流式读写处理大文件，配合独立 `stdinQueue`/`stdoutQueue` 双队列 8MB 背压限流、分块 `autoreleasepool` 及时释放（64MB 流式实测峰值 RSS 增量 `< 32MB`）以及独立的 `0600` 权限口令令牌文件隔离。
- **沙盒安全的零数据丢失原地覆盖（`commitStagedFile`）**：通过 POSIX `statfs` 计算扣除被覆盖文件后的净需磁盘空间（`max(0, stagedSize - existingSize)`），先执行 `open(O_WRONLY)` 权限预检与回滚备份（`original.bak`），再通过 `ftruncate` + 流式写入 + `fsync` 原地更新目标文件，既保留了 `NSSavePanel` 沙盒授权与 inode，又确保权限拒绝或中途 I/O 错误时原文件完好无损。
- **系统钥匙串与 Touch ID 生物识别（`KeychainService`）**：基于 macOS Data Protection Keychain 与 `LocalAuthentication`（`.userPresence`）安全存取私钥口令，支持 Touch ID、Apple Watch 与系统密码回退，并结合单次子进程调用的 `GPGService.resolvePrimaryFingerprint` 与强类型 `GPGError.ambiguousKeyReference` 实现高速主钥/子钥指纹解析。
- **内存清零与暂存目录生命周期管理（`SecureMemory` & `TransientFileRegistry`）**：通过 Darwin `memset_s` 在释放时尽力清零内部字节缓冲区，在应用退出（`NSApplication.willTerminateNotification`）时自动清零覆写并清理暂存目录，并在启动时清理超过 24 小时的残留目录。
- **独立命令行伴侣工具（`moaiy-cli`）**：提供独立的 `MoaiyCLI` 可执行程序，内置 `SIGPIPE` 防护，支持 `status`（含 Kyber-768 能力检测）、`list-keys`、`encrypt` 与 `decrypt` 子命令。

### 详细更新

#### 新增

- 新增 `StreamingCryptoPipeline` 流式加解密管道，支持 256KB 分块读写、独立 `stdinQueue`/`stdoutQueue` 双队列 8MB 背压限流、分块 `autoreleasepool` 内存及时释放（64MB 流式传输峰值 RSS 增量 `< 32MB`）、非阻塞 `readabilityHandler` 管道读取以及独立的 `0600` 权限口令令牌文件隔离。
- 新增 `CryptoProgress` 与 `StreamingProgressReporter` 进度通知器，支持 10Hz 防抖节流，避免大文件传输时 UI 渲染拥塞。
- 新增 `SecureMemory` 内存安全工具（`SecureBytes`、`SecureString`），在释放时通过 Darwin `memset_s` 尽力清零内部字节缓冲区。
- 新增 `TransientFileRegistry` 临时目录生命周期跟踪器，接入 `SecureTempStorage` 与 `NSApplication.willTerminateNotification`，在应用退出时自动清零并移除挂起目录，并在启动时清理超过 24 小时的陈旧残留目录。
- 新增 `KeychainService` 系统钥匙串服务，集成 macOS Data Protection Keychain 与 `LocalAuthentication`（`.userPresence`），支持 Touch ID、Apple Watch 与系统密码回退、后台线程非阻塞读取，以及仅限 `#if DEBUG` 编译期的旧版钥匙串受控回退。
- 新增单次子进程调用的 `GPGService.resolvePrimaryFingerprint`（基于 `--list-secret-keys --with-colons --fixed-list-mode`）与强类型错误 `GPGError.ambiguousKeyReference`，一次性解析 8 位短 ID、16 位长 ID、主钥指纹及子钥指纹。
- 新增独立 `moaiy-cli` 命令行伴侣工具（`MoaiyCLI` Target），内置 `SIGPIPE` 防护，完整支持 `status`（含 Kyber-768 算法探测）、`list-keys`、`encrypt` 与 `decrypt` 子命令。
- 在 `GPGService` 与 `KeyActionMenu` 中接入 `encryptFileStreaming` 与 `decryptFileStreaming`，并与 `decryptFile` 保持完整行为对齐（`--status-fd 2`、`DECRYPTION_OKAY` 校验、指定私钥匹配校验及钥匙串口令自动读取）。

#### 变更

- 将应用营销版本号升级至 `1.0.0`，工程构建版本号递增至 `10`。
- 加固 `SecureTempStorage.commitStagedFile` 原地覆盖安全性：通过 POSIX `statfs` 计算扣除被覆盖文件后的净需空间（`max(0, stagedSize - existingSize)`），执行 `open(O_WRONLY)` 权限预检、回滚备份（`original.bak`）清零销毁，以及 `ftruncate` + 流式写入 + `fsync` 原地覆盖，在保留 `NSSavePanel` 沙盒授权与目标文件 inode 的同时杜绝权限或 I/O 错误导致的数据丢失。
- 在 `MoaiyApp` 启动入口中初始化 `TransientFileRegistry` 退出清理挂钩。

#### 安全

- 对临时口令令牌文件与操作暂存目录强制执行 `0600`/`0700` 权限，并在删除前执行清零覆写（`zeroScrubDirectoryContents` + `fsync`）。
- 将 `KeychainService` 的旧版钥匙串回退严格限制在 `#if DEBUG` 编译期（`allowLegacyKeychainFallback`），确保 Release 构建在缺失 Entitlement 时严格失败关闭。

### 兼容性与已知说明

- **抗量子密钥互操作性**：Kyber-768 混合 OpenPGP 密钥需要 GnuPG 2.5.21+ 或兼容的 OpenPGP 实现；与旧版工具交换密钥时请选用 RSA-4096 或 ECC。
- **沙盒原地覆盖说明（`commitStagedFile`）**：为保留 macOS App Sandbox 下 `NSSavePanel` 授予的单文件安全作用域权限，覆盖已有文件时采用原地更新（`ftruncate` + 流式写入 + `fsync`）并配合清零销毁的回滚备份（`original.bak`）。若进程在写入中途遭遇不可捕获的异常终止（如 `SIGKILL` 或断电），目标文件可能处于截断状态，回滚备份将在 `SecureTempStorage` 中最长保留 24 小时。
