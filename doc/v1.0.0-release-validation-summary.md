# Moaiy v1.0.0 Implementation & Architecture Status Summary

## 1. Executive Summary
This document summarizes the current engineering state of the Moaiy v1.0.0 milestone. The deliverables focus on resolving critical architectural bottlenecks identified in earlier evaluations, introducing streaming process I/O with dual-queue backpressure, best-effort memory clearing, system Keychain integration, and a companion CLI tool, while strictly preserving macOS App Sandbox security invariants.

## 2. Milestone Deliverables by Sprint

### Sprint 0: Engineering Infrastructure & Invariants
- **`.cursorrules`**: Architectural rules covering macOS App Sandbox resource pairing, non-blocking asynchronous pipe draining with separate I/O queues, and internal buffer zeroization.
- **`AGENTS.md`**: Directory layout, workflow directives, and high-risk engineering boundaries (tracked in git).
- **`specs/` Hierarchy**: Specifications for streaming I/O with backpressure, resilience, Keychain integration, and CLI companion.
- **`scripts/loop-runner.sh`**: Robust syntax, multi-file parse verification, and test execution harness.

### Sprint 1: Streaming Pipeline, Staging & Resilience
- **WP-1 (`StreamingCryptoPipeline.swift` & `GPGService.swift`)**:
  - Implemented 256KB chunked streaming I/O with **independent serial queues (`stdinQueue` and `stdoutQueue`)** and **backpressure throttling** (max 8MB in-flight buffer) to guarantee constant memory consumption (<50MB RSS) under load.
  - Eliminated process pipe deadlocks by reading standard output and standard error asynchronously via `readabilityHandler` and `pipeGroup` EOF synchronization.
  - Isolated passphrase handling: passphrases are written to a dedicated temporary token file created with `open(O_CREAT | O_EXCL, 0o600)`, passed via `--passphrase-file`, and overwritten with zeros before `unlink`, preventing sensitive secrets from leaking into standard input or plaintext.
  - Handled early child termination, stdin read errors, stdout write errors, and `SIGPIPE` safely.
  - Set plaintext output permissions to `0o600` and ciphertext permissions to `0o644`.
  - Reverted `GPGService.writeStagedOutput` to safe in-place overwrite to strictly respect user-granted App Sandbox save-panel security scopes, with pre-flight available disk space validation.
  - Directly exposed `encryptFileStreaming` and `decryptFileStreaming` on `GPGService`, and wired them into `KeyActionMenu.swift` for actual UI dispatch.
  - `StreamingProgressReporter` features 10Hz UI throttling.
- **WP-2 (`SecureMemory.swift`, `TransientFileRegistry.swift`)**:
  - `SecureBytes` & `SecureString` provide best-effort internal buffer clearing via Darwin `memset_s` upon deallocation.
  - `TransientFileRegistry` actively tracks directories created by `SecureTempStorage` and hooks into `NSApplication.willTerminateNotification` to purge active scratch directories on application exit. Startup routines continue to clear stale items from prior abnormal exits via `cleanupStaleDirectories()`.

### Sprint 2: System Integration & CLI Companion
- **WP-3 (`KeychainService.swift`)**:
  - Integrated Apple Keychain Services with `LocalAuthentication` (`.userPresence`), supporting Touch ID, Apple Watch, and device passcode fallback.
  - Uses `kSecUseDataProtectionKeychain: true` and add-then-update logic (`SecItemAdd` with fallback to `SecItemUpdate` and delete+add fallback) to avoid data loss.
  - Dispatches blocking `SecItemCopyMatching` calls to background queues to avoid freezing the MainActor.
  - Uses non-deprecated `LAContext.interactionNotAllowed = true` for silent credential probing.
  - Added `resolvePrimaryFingerprint(for:)` in `GPGService` to map short/long key IDs to 40-character primary fingerprints before Keychain lookup.
  - Wired into `GPGService.decryptFile` and `decryptFileStreaming` with explicit handling of `KeychainError.userCancelled` and `KeychainError.authenticationFailed`.
- **WP-4 (`MoaiyCLI/main.swift`)**:
  - Standalone `moaiy-cli` companion tool.
  - Fully implemented subcommands: `status` (with structured GnuPG config parsing for Kyber-768), `list-keys` (supporting `--secret`), `encrypt`, and `decrypt`.
  - Non-blocking concurrent pipe handling to eliminate stdout buffer deadlocks.
  - Auto-discovers Moaiy App's sandboxed container home (`~/Library/Containers/com.moaiy.app/Data/Library/gnupg`), `~/Library/gnupg`, system `~/.gnupg`, or custom `--gpg-home`.
  - Documented non-interactive execution constraints (`--batch`, `--yes`, gpg-agent passphrase requirement) in `--help`.
  - Unified version string: `1.0.0`.

### Sprint 3: Versioning & Documentation

- Maintained truthful bilingual `CHANGELOG.md` entry.
