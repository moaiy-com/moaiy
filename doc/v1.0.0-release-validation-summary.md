# Moaiy v1.0.0 Implementation & Architecture Status Summary

## 1. Executive Summary
This document summarizes the current engineering state of the Moaiy v1.0.0 milestone. The deliverables focus on resolving critical architectural bottlenecks identified in earlier evaluations, introducing streaming process I/O, best-effort memory clearing, system Keychain integration, and a companion CLI tool, while strictly preserving macOS App Sandbox security invariants.

## 2. Milestone Deliverables by Sprint

### Sprint 0: Engineering Infrastructure & Invariants
- **`.cursorrules`**: Architectural rules covering macOS App Sandbox resource pairing, non-blocking asynchronous pipe draining, and internal buffer zeroization.
- **`AGENTS.md`**: Directory layout, workflow directives, and high-risk engineering boundaries (tracked in git).
- **`specs/` Hierarchy**: Specifications for streaming I/O, resilience, Keychain integration, and CLI companion.
- **`scripts/loop-runner.sh`**: Non-blocking syntax and test execution script.

### Sprint 1: Streaming Pipeline, Staging & Resilience
- **WP-1 (`StreamingCryptoPipeline.swift` & `GPGService.swift`)**:
  - Implemented 256KB chunked streaming I/O with non-blocking `readabilityHandler` callbacks on dedicated background queues to prevent Swift Concurrency cooperative thread starvation.
  - Eliminated process pipe deadlocks by reading standard output and standard error asynchronously.
  - Isolated passphrase handling: passphrases are written to a dedicated temporary token file with `0o600` permissions and passed via `--passphrase-file`, preventing sensitive secrets from prepending to file data on standard input.
  - Handled early child termination and `SIGPIPE` safely.
  - Set plaintext output permissions to `0o600` and ciphertext permissions to `0o644`.
  - Reverted `GPGService.writeStagedOutput` to safe in-place overwrite to strictly respect user-granted App Sandbox save-panel security scopes.
  - Directly exposed `encryptFileStreaming` and `decryptFileStreaming` on `GPGService`.
  - `StreamingProgressReporter` features 10Hz UI throttling.
- **WP-2 (`SecureMemory.swift`, `TransientFileRegistry.swift`)**:
  - `SecureBytes` & `SecureString` provide best-effort internal buffer clearing via Darwin `memset_s` upon deallocation.
  - `TransientFileRegistry` actively tracks directories created by `SecureTempStorage` and hooks into `NSApplication.willTerminateNotification` to purge active scratch directories on application exit. Startup routines continue to clear stale items from prior abnormal exits via `cleanupStaleDirectories()`.

### Sprint 2: System Integration & CLI Companion
- **WP-3 (`KeychainService.swift`)**:
  - Integrated Apple Keychain Services with `LocalAuthentication` (`.userPresence`), supporting Touch ID and device passcode fallback.
  - Uses `kSecUseDataProtectionKeychain: true` and add-then-update logic (`SecItemAdd` with fallback to `SecItemUpdate`) to avoid data loss.
  - Dispatches blocking `SecItemCopyMatching` calls to background queues to avoid freezing the MainActor.
  - Uses non-deprecated `LAContext.interactionNotAllowed = true` for silent credential probing.
  - Wired into `GPGService.decryptFile` for automatic passphrase resolution.
- **WP-4 (`MoaiyCLI/main.swift`)**:
  - Standalone `moaiy-cli` companion tool.
  - Fully implemented subcommands: `status` (with structured GnuPG config parsing for Kyber-768), `list-keys` (supporting `--secret`), `encrypt`, and `decrypt`.
  - Non-blocking concurrent pipe handling to eliminate stdout buffer deadlocks.
  - Auto-discovers Moaiy App's managed home (`~/Library/gnupg`), system `~/.gnupg`, or custom `--gpg-home`.
  - Unified version string: `1.0.0`.

### Sprint 3: Versioning & Documentation
- Upgraded marketing version to `1.0.0` (Build `10`) in `Moaiy.xcodeproj/project.pbxproj`.
- Maintained truthful bilingual `CHANGELOG.md` entry.
