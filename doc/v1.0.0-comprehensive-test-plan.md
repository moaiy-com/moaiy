# Moaiy v1.0.0 全面测试与质量保障计划 (Comprehensive Test Plan)

## 1. 测试背景与目标

随着 Moaiy 完成 v1.0.0 的核心特性开发与关键缺陷收敛，系统引入了多项关键架构组件（流式 I/O 管道、口令隔离、钥匙串与生物识别集成、独立 CLI 伴侣工具）。作为一款去中心化、本地优先的桌面加密工具，软件的稳定性直接关系到用户的数据主权与资产安全。

本测试计划确立了一套兼顾静态代码合规、自动化单元测试与真机手工验证的测试标准与执行矩阵。所有评估严格区分已验证项（Verified）与需真机交互验证项（Pending Manual QA），杜绝夸大测试结论。

## 2. 测试范围与模块拆解

```
Moaiy v1.0.0 测试架构全景：
├── 1. 核心密码学与流式引擎 (Crypto & Streaming Core)
│   ├── GPG/OpenPGP (包含 Kyber-768 PQC 混合模式)
│   ├── StreamingCryptoPipeline (256KB 分块、readabilityHandler 异步读、管道防死锁、口令文件隔离)
│   └── GPGService.writeStagedOutput (保存面板授权范围内的原地覆盖)
├── 2. 内存生命周期与暂存清理 (Memory Safety & Temp Storage)
│   ├── SecureMemory (SecureBytes / SecureString 借助 memset_s 尽力而为清零其内部缓冲区)
│   └── TransientFileRegistry + SecureTempStorage (NSApplication.willTerminate 退出清理挂钩)
├── 3. 系统级集成与硬件融合 (System Integration & Biometrics)
│   ├── KeychainService (Generic Password 存取与域隔离、Add-then-Update 幂等写入)
│   └── LocalAuthentication (.userPresence 支持 Touch ID 与设备密码回退、后台线程检索)
├── 4. 伴侣工具与接口对齐 (Companion CLI & Tooling)
│   └── moaiy (status / list-keys / encrypt / decrypt / --secret / --json)
└── 5. 跨版本平台与沙盒合规 (Platform, Sandbox & Packaging)
    ├── App Sandbox (Security-Scoped Bookmarks 成对释放)
    ├── 11 语种全量本地化与深浅色视觉系统
    └── 苹果公证 (Notarization) 与 Gatekeeper 合规
```

## 3. 多层级测试策略 (Testing Strategy)

| 测试层级 | 测试类型 | 工具与框架 | 核心关注点与状态 |
| :--- | :--- | :--- | :--- |
| **L1: 单元测试** | 白盒功能验证 | Swift Testing / XCTest | 算法正确性、边界条件、错误映射（代码已就绪） |
| **L2: 沙盒集成测试** | 权限与生命周期 | `MoaiySandboxTest` | 拖拽授权安全作用域、容器存储路径、子进程隔离（需在 Xcode 中真机交互运行） |
| **L3: 内存与静态扫描** | 安全与并发检测 | ASan, TSan, Clang Static Analyzer | 扫描 Swift Concurrency 状态机与外部进程 Pipes 读写，排查数据竞争 |
| **L4: 性能与大文件压测** | 吞吐与常驻内存 | 自动化压力测试脚本 / Instruments | 100MB~50GB 文件加解密；验证常驻内存是否稳定在 50MB RSS（待压测执行） |
| **L5: 异常故障恢复** | 故障自愈测试 | 进程注入 / 信号捕获 (SIGINT/SIGKILL) | 目标文件零破坏、未加密密文零碎片残留（退出清理已接入） |
| **L6: 系统与硬件矩阵** | 跨环境黑盒验证 | 物理 Mac (M系列 + Intel) + macOS 13/14/15 | 需在物理设备上手工验证 Touch ID 弹窗、Keychain 解锁与 DMG 安装公证 |

## 5. 准入门禁与发布核查清单 (Release Gate Checklist)

- [x] **代码编译与语法自洽**：所有新增与重构源码通过 Swift 6.4 编译器语法检查。
- [x] **沙盒权限合规**：保存面板文件写回保留原地覆盖逻辑，不违反 sandbox entitlement。
- [x] **口令与管道安全**：流式管道中口令完全独立于 stdin 文件数据流，杜绝口令被加密入密文。
- [x] **生命周期挂钩真实生效**：`TransientFileRegistry` 深度绑定 `SecureTempStorage` 与 `willTerminate`。
- [x] **CLI 功能对齐**：`moaiy` 完整实现 `encrypt`/`decrypt`/`status`/`list-keys`，并支持 `--secret`。
- [ ] **物理硬件验收（待人工）**：在真实搭载 Touch ID 的 Mac 设备上测试指纹弹窗与钥匙串解密。
- [ ] **大文件实际性能压测（待跑测）**：在本地开发机执行 10GB+ 文件连续加解密，使用 Instruments 记录内存占用。
