# Moaiy v1.0.0 全面测试与质量保障计划 (Comprehensive Test Plan)

## 1. 测试背景与目标

随着 Moaiy 完成从 v0.9.0 到 v1.0.0 的四个冲刺迭代，系统引入了多项重构与关键特性（大文件流式管道、系统原子替换、内存主动清零、钥匙串与生物识别集成、独立 CLI 伴侣工具）。作为一款去中心化、本地优先的桌面加密工具，软件的稳定性直接关系到用户的数据主权与资产安全。

本测试计划旨在确立一套完备、严谨、可度量的测试标准与执行矩阵，确保 Moaiy v1.0.0 正式版在功能完整性、密码学安全性、系统级沙盒合规性、内存与性能边界以及跨环境兼容性上达到企业级发布标准。

---

## 2. 测试范围与模块拆解

```
Moaiy v1.0.0 测试架构全景：
├── 1. 核心密码学与流式引擎 (Crypto & Streaming Core)
│   ├── GPG/OpenPGP (包含 Kyber-768 PQC 混合模式)
│   ├── StreamingCryptoPipeline (256KB 分块、AsyncStream、管道防死锁)
│   └── AtomicFileUtility (同卷隐藏临时文件与 replaceItemAt 原子覆盖)
├── 2. 内存安全与生命周期韧性 (Memory Safety & Resilience)
│   ├── SecureMemory (SecureBytes / SecureString 借助 memset_s 内存清零)
│   └── TransientFileRegistry (NSApplication.willTerminate 退出清理挂钩)
├── 3. 系统级集成与硬件融合 (System Integration & Biometrics)
│   ├── KeychainService (Generic Password 存取与域隔离)
│   └── LocalAuthentication (Touch ID / Apple Watch 硬件鉴权与降级)
├── 4. 伴侣工具与接口对齐 (Companion CLI & Tooling)
│   └── moaiy-cli (status / list-keys / encrypt / decrypt / --json)
└── 5. 跨版本平台与沙盒合规 (Platform, Sandbox & Packaging)
    ├── App Sandbox (Security-Scoped Bookmarks 成对释放)
    ├── 11 语种全量本地化与深浅色视觉系统
    └── 苹果公证 (Notarization) 与 Gatekeeper 合规
```

## 3. 多层级测试策略 (Testing Strategy)

| 测试层级 | 测试类型 | 工具与框架 | 核心关注点与验收阈值 |
| :--- | :--- | :--- | :--- |
| **L1: 单元测试** | 白盒功能验证 | Swift Testing / XCTest | 算法正确性、边界条件、错误映射；覆盖率目标 >85% |
| **L2: 沙盒集成测试** | 权限与生命周期 | `MoaiySandboxTest` | 拖拽授权安全作用域、容器存储路径、子进程隔离 |
| **L3: 内存与静态扫描** | 安全与并发检测 | ASan, TSan, Clang Static Analyzer | 零数据竞争（Data Races）、零非法内存越界访问、零悬挂指针 |
| **L4: 性能与大文件压测** | 吞吐与常驻内存 | 自动化压力测试脚本 / Instruments | 100MB~50GB 文件加解密；常驻内存严格低于 50MB RSS |
| **L5: 异常故障恢复** | 故障自愈测试 | 进程注入 / 信号捕获 (SIGINT/SIGKILL) | 目标文件零破坏、未加密密文零碎片残留、100% 临时文件清理 |
| **L6: 系统与硬件矩阵** | 跨环境黑盒验证 | 物理 Mac (M系列 + Intel) + macOS 13/14/15 | Touch ID 生物识别认证、钥匙串持久化、DMG 安装公证通过 |

## 5. 执行阶段与缺陷退出标准 (Release Gates)

### 执行阶段排期
1. **第一阶段：基准冒烟与单元自动化跑环 (Day 1)**
   - 触发 `loop-runner.sh` 与 Xcode 单元测试，保证所有 P0 核心用例全部通过。
2. **第二阶段：内存扫描与大文件专项压测 (Day 2-3)**
   - 启用 ASan/TSan 编译测试；运行 10GB/50GB 大文件压力流水线，确保 RSS 内存平稳。
3. **第三阶段：物理真机与系统环境矩阵验证 (Day 4)**
   - 在 M1/M2/M3/M4 与 Intel 实机上测试 Touch ID 鉴权、休眠唤醒以及热拔插行为。
4. **第四阶段：公证打包与发布验收 (Day 5)**
   - 最终二进制构建、Gatekeeper 校验与双语发布说明核对。

### 发布准出门禁 (Exit Criteria)
- [ ] **P0（致命/阻断性）缺陷为 0**：无崩溃、无数据损坏、无内存泄漏失控。
- [ ] **P1（严重性）缺陷为 0**：所有核心加解密回环 100% 成功。
- [ ] **自动化测试通过率 100%**：XCTest 与 `MoaiySandboxTest` 无任何失败断言。
- [ ] **内存稳定度达标**：50GB 加解密过程中常驻内存始终保持在 50MB 以内。
- [ ] **苹果代码签名与公证通过**：完成 Hardened Runtime 签名并获得 Apple 官方公证票据。
